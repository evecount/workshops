# Formats & Booking

All workshops are available **in person (Singapore)** or **live remote** for engineering teams, universities, startups, and developer communities.

## Session Formats

| Format | Duration | Best For | Deliverable |
| :--- | :--- | :--- | :--- |
| **Technical Seminar** | 90 min – 2 hrs | Meetups, university guest lectures, leadership briefings | Live architecture walkthrough + Q&A + repo access |
| **Half-Day Intensive** | 3.5 hours | Engineering & product teams | Hands-on coding lab on 1 selected repository |
| **Full-Day Deep Dive** | 6–7 hours | ML/AI teams shipping production systems | 2–3 paired modules + tailored benchmark / architecture review |
| **Multi-Week Cohort** | 3–6 sessions | Accelerators, universities, R&D teams | Guided implementation from research repo to working prototype |
